QUICK START
================================================================================

1. START DEV SERVER
   $ npm run dev
   → Opens at http://localhost:5173/

2. CREATE JOURNAL ENTRY
   → Click "New Entry" or go to /new
   → Fill in mood and content
   → Click "Save Entry"

3. VIEW ALL ENTRIES
   → Go to "My Journals" page
   → Search, filter, sort as needed
   → Click to view/edit/delete

4. BUILD FOR PRODUCTION
   $ npm run build
   → Creates optimized build in dist/
